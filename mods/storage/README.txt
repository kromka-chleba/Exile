# Exile Mod: Storage
===============================================================================
Adds api for storage containers 

`storage.register_storage(name,def)`
Will register a standard storage that is a nodebox with certain shape parameters with name and def
- Will be 8x4 in terms of inventory space (unless specified with formspec_width and formspec_height)
- paramtype is "light" by default

- def is a "definition" table of custom node definitions or other
